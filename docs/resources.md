# Resources shared by organizers

1. [AI Poker Tutorial](https://chisness.github.io/2020-07-05/ai-poker-tutorial) — conceptual background on poker bots, game theory and related algorithms.
2. [Zenodo record 17136841](https://zenodo.org/records/17136841) — large poker hand-history research dataset, optional reference; not required to build or submit a bot.
3. [Official starter kit](https://github.com/FreddyyAndrews/poker-hackathon-kit) — the relevant engine, reference agents, submission rules, validator and code interface. Its original README is preserved in [official-starter-kit.md](official-starter-kit.md).

Prioritize building and validating against the starter kit, not training on the external dataset first.
